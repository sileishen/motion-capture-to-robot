# RoleMotion Pipeline

RoleMotion Pipeline 项目主页，展示从 data acquisition 到 Unitree G1 deployment 的完整工程路线。Processing 输出可进入 StableMoFusion 训练与推理，也可直接进入 GMR；生成动作还可分别进入 Evaluator 与机器人链路。

在线访问：<https://sileishen.github.io/motion-capture-to-robot/>

## Website structure

- `index.html`：页面结构与内容
- `style.css`：视觉样式与响应式布局
- `script.js`：导航、图片预览与 Technical Details 交互
- `assets/`：项目图片与 teaser

The site is published with GitHub Pages from the `main` branch.
